# Agents

Sub-agent di Claude Code dedicati a compiti isolati per questo progetto:

- **qa.md** — testa il sito (link, pulsanti, responsive, dati strutturati) dopo ogni modifica.
- **reviewer.md** — fa code review su qualità, sicurezza e aderenza a `CLAUDE.md`/`.claude/rules/` prima di un commit.
- **researcher.md** — raccoglie dati reali e riferimenti prima di scrivere codice per un nuovo sito/sezione.
